# 0.1.0 工程预览说明

日期：2026-09-21；程序VERSION=0.1.0，数据库schema=1。这是本地开发预览，工程M1—M3尚在逐项验收；不是已完成全部PRD的正式发布。远端仓库为空，未推送、未公网部署。当前已提交实现的取得方式见README本地副本步骤；用git rev-parse HEAD记录所用程序提交。

## 本版功能

- 七模块目录与唯一数据写入权、SQLite不可变版本/事务/迁移、乐观锁、可重试的跨模块变更通知。
- 议题→材料→说法/事件→判断/情景/影响路径→复盘/JSON与Markdown导出；固定引用和人工假设保留。
- RSS、WDI和GDELT DOC免费接入；另有默认关闭的GKG最新批次元数据通道，共享GDELT预算。AI/收费/航空船舶未接入，默认关闭。
- 来源失败/配额/部分覆盖、分页阅读状态、纠错依赖重审；研究地图不补造精确坐标或实时轨迹。
- 本地初始化/幂等启动/配置检查、在线一致性备份、空目录恢复、保护工作区的更新及程序/数据库成对回退。
- 回收站恢复与明确授权的期限清理；读取/搜索/导出时执行来源权限，恢复保留后来收紧的来源政策事实。

## 兼容性与恢复

使用Python3.11与标准库SQLite，已实测macOS15.6.1 arm64/Apple M1；其他平台不冒充本机验收。运行时不需安装npm/pip包。共享Store的新增对象仍使用schema1，但开发期旧提交未必理解新权限事实；不要手动切回任意旧代码并直接打开新数据。使用已记录版本及本项目update/rollback流程，升级前备份，新增记录后回退会停止以保护新写入。具体命令和缺依赖/端口/磁盘/迁移失败排查见README与LOCAL_OPERATIONS。

## 已验证与已知限制

具体实际证据、失败和未执行项见[验收矩阵](ACCEPTANCE.md)及[当前进度](PROGRESS.md)；启动、恢复、更新和故障处理见[本地运行说明](LOCAL_OPERATIONS.md)，本批收取凭据、恢复策略、完整回归和最终容量结果见[最终整合验证](evidence/final-integration-20260921.md)。异常退出、备份恢复、成功更新、故障回退、10条官方材料和容量性能已有实测；这些不能代替未完成的精确分支。[Finder双击验收](evidence/finder-double-click-preparation-20260921.md)现已完成启动、幂等复用、自动打开页面和停止保留数据；真实OS睡眠唤醒尚未验证。质量抽查及七天观察/十分钟效率仍待完成。

GDELT DOC真实请求仍失败；GKG成功并不说明DOC可用，也不保证停机历史覆盖或主题召回相关性。批次时间不是原文发布时间。付费与AI不会被自动启用；无真实采集状态时使用显式未知/失败/部分覆盖。

发现启动故障先执行本地check-config并保留日志；更新或恢复故障先查看运维记录和被保留的恢复点，不重置Git工作区、不清理资料目录。不得用数据库为空或仅health成功代替研究记录、附件、历史引用和阅读状态检查。
